# La Mujer con Chalina — V1

Prototipo web estático para la primera ronda exploratoria de evaluación.

## Publicación con GitHub Pages

1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. Guarda. GitHub Pages publicará el sitio en unos minutos.

El archivo de entrada es `index.html`.

## Alcance y limitaciones de esta versión

- Es un prototipo narrativo de evaluación, no un servicio terapéutico.
- La representación visual es conceptual; esta versión no genera una imagen personalizada mediante IA.
- El formulario de feedback genera un archivo JSON que el participante descarga en su dispositivo.
- Las respuestas no se envían a un servidor ni se recopilan automáticamente.
- No se deben introducir nombres completos, direcciones exactas ni información sensible.
- La participación debe ser voluntaria y la persona puede abandonar la experiencia cuando quiera.

## Versionado

Esta carpeta corresponde a **V1**, destinada a la primera ronda de feedback. Las mejoras posteriores deben documentarse en versiones separadas.
